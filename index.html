Frequently Asked Questions

Everything you need to know about ShortScroll

Is ShortScroll completely free to use? ▼

Yes! ShortScroll is 100% free with no hidden paywalls, no subscriptions, and no injected advertisements.

Do I need to log into my accounts inside ShortScroll? ▼

ShortScroll works without logging in for public feeds. If you prefer to access your personalized recommendations, you can log in through the embedded WebView — your session credentials remain securely saved on your own computer.

How do I install the Browser Extension? ▼

Simply click Get on Microsoft Edge to install directly from the official Microsoft Edge Add-ons store with 1 click. Chrome Web Store support will be available soon.

How do I install or run ShortScroll on Linux? ▼

• Ubuntu / Debian / Mint: Download ShortScroll-Linux-x64.deb and double-click to install via your software manager, or run sudo dpkg -i ShortScroll-Linux-x64.deb.
• Universal Portable (Arch/Fedora): Download ShortScroll-Linux-x64.tar.gz, extract it, and run ./ShortScroll.
